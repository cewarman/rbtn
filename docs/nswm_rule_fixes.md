## 評估方法與限制

### 偵測器怎麼運作

錯誤分析用的是規則式偵測器（不在本 repo 內），對每筆標記做：

1. **數值反推**：把唸法中的中文/英文數字反推回數值，與原文的阿拉伯數字比對（已處理百分比、分數、比數、日期、序數、廿/卅、○、萬/億單位等合法唸法）。
2. **邊界檢查**：標記前一字是數字或小數點、後一字是數字、%、小數點+數字、千分位逗號，視為截斷。
3. **結構檢查**：offset 對不回原文、規則欄含非規則內容、原文含 tab、唸法殘留阿拉伯數字、唸法與原文相同。
4. **一致性**：同一原文字串在全語料中的少數派唸法（<10%）。

### 數字的意義

- 偵測器標出的是**疑似錯誤**，不是 ground truth。它有誤報（例如 `二0四0年` 內夾雜 ASCII 0、`40 to 50` 雙空白）也有漏報（唸法錯但數值一致，例如球隊名 `76人` 唸成七十六人）。
- 因此「修正前 vs 修正後」的筆數是**同一把尺量兩次的相對比較**，可以作為工程改善的證據，但不能直接換算成正確率。
- 日/號、星期/禮拜是轉換函式的隨機變體，不算錯誤；比較時已排除。
